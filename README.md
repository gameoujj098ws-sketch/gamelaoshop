# Game Lao Shop

ช่วยเขียนโค้ดเว็บไซต์เว็บไซต์เติมเกมออนไลน์หน้าหลักให้มีแถบด้านบนแถบด้านล่างแถบด้านล่างให้เป็นเมนูเมนูแถบด้านล่างจากซ้ายไปขวาเติมเกมให้เป็นหน้าหลักแล้วก็เหด้านล่างต่อจากเติมเกมให้เป็นรูปไอคอนสวยสวยเขียนคำว่าประวัติแล้วก็หัดป้ายให้เป็นรูปไอคอนกระเป๋าเงินเขียนคำว่าเติมเครดิตแล้วก็หักไปบัตรเติมหรือบัตรเกม คืออันสุดท้ายในแถบเมนูด้านล่างแถบเมนูด้านบนซ้ายสุดให้เป็นโลโก้ขวาสุดให้เป็นรูปวงกลมโปรไฟล์เล็กๆหากกดวงกลมโปรไฟล์ให้เป็นหน้าเมนูหน้าเมนูให้มีเติมเงินข้อความโปรไฟล์ประวัติเติมเกมประวัติเติมเกมประวัติเติมการประวัติการเข้าอื่นๆตั้งค่าทั่วไปออกจากระบบ ตั้งค่าทั่วไปไม่ต้องเพิ่มมาก็ได้เดสบอร์ดสินค้าให้มีคำว่าเกมที่ได้รับความนิยมให้เขียนไปว่ายังไม่มีสินค้าหาแอดมินได้เพิ่มมาหากแอดมินเพิ่มมาแล้วให้เป็นแบบรูปพี่หนึ่ง แล้วก็ต่อจากเกมที่ได้รับความนิยมมาด้านล่างให้เป็นคำว่าบัตรเติมเงินเป็นบัตรต่างๆที่เป็นแถวเดียวสามารถเลื่อนไปด้านข้างได้ทำตามรูปที่สองแล้วก็ต่อจากบัตรเติมเงินมาด้านล่างให้เป็นเกมอื่นๆให้แสดงเกมอื่นๆที่เพิ่มแอดมินเพิ่มมาถ้าหากไม่ได้เพิ่มก็เขียนว่ายังไม่มีหรือยังไม่ได้เพิ่ม แล้วก็หากแอดมินเพิ่มมาหากคุณต้องการเติมเกมไหนยกตัวอย่างเกมฟรีไฟล์หากกดเติมเข้าไปให้เป็นหน้าป๊อบอัพรูปไอคอนฟรีไฟล์มีชื่อฟรีไฟล์ข้อมูลคู่เล่นกรอก TrueID เลือก package ว่าจะเติมเท่าไหร่แล้วก็ปุ่มด้านล่างคือปุ่มยืนยันชำระเงินแล้วก็เมนูเติมเงิน สามารถเติมด้วย QR Code หากกดเข้าไปตรงคำว่าเติมเงินให้มีสองทางเลือกคือหนึ่งเติมด้วย QR Code สองเติมด้วยโค้ดโค้ดจะเข้าฮทันทีส่วน QR Code หากกดเข้าไปให้เลือกจำนวนที่จะสร้าง QR Code ตัวอย่าง 10,000 กีบ 50,000 กีบ 100,000 กีบ 200,000 กีบ 500,000 กีบ 1,000,000 กีบหากต้องการกำหนดเองให้มีช่องสามารถกำหนดจำนวนเงินที่จะสร้าง QR Code เองหากกดเลือกจำนวนเสร็จให้กดปุ่มอยู่ด้านล่างให้กดคำว่าสร้าง QR Code หากกดสร้างให้เด้งเข้ามาในหน้าให้ชำระเงินมีรูป QR Code แสดงจำนวนเงินที่สร้างไว้ แล้วก็มีเวลา 15 นาทีคิวอาร์นั้นที่สร้างไว้จะหายไปแล้วก็ลงมาด้านล่างให้เป็นช่องแนบรูปภาพแนบรูปสลิปหากแนบรูปลงไปให้ระบบทำงานทันทีเราจะทำเป็นเป็นระบบตรวจยอดเงินอัตโนมัติให้ตรวจยอดเงินที่ค้างไว้ให้ตรงกับสลิปที่โอนให้ตรวจชื่อบัญชีผู้รับตรวจว่าสลิปนี้เป็นวันที่นี้โอนจริงๆ แล้วก็เมนูจัดการหลังบ้านจัดการแอดมินให้มีหน้าเว็บบอกแอดมินสิ่งที่ต้องมีในแง่บอกแอดมินคือหนึ่งสิติบอกจำนวนสมาชิกทั้งหมดยอดขายหนึ่งเดือนรีหนึ่งครั้งแสดงว่ายอดขายได้ขายไปเท่าไหร่สองเมนูคู่ผู้ใช้แสดงชื่อผู้ใช้ในเว็บทั้งหมดให้มีแสดงชื่อผู้ใช้แต่ละคนเป็นแถบแล้วก็พร้อมกับช่องค้นหาสามารถค้นหา ชื่อผู้ใช้ได้เมนูที่สามหมวดหมู่สามารถลงหมวดหมู่ กดไปที่หมวดหมู่สามารถเพิ่มหมวดหมู่ได้มีปุ่มเพิ่มสามารถใส่ลิ้งค์รูปภาพของเกมได้ใส่ชื่อได้แล้วก็มีปุ่มเพิ่มหากเพิ่มให้มาอยู่ในหน้าเดสบอร์ดหมวดหมู่มีปุ่มบวกแพ็คเกจหากปุ่มกดบวกเข้าไปให้เป็นสามารถบวกแพ็คเกจไปได้ก็ตรงหน้าที่เราเพิ่มหมวดหมู่มากให้มีสามปุ่มคือเพิ่ม package แล้วก็สองเพิ่มข้อความให้ลูกค้ากรอกเช่นยูไอดีเกมสามารถใส่ช่องกรอกได้หนึ่งสองช่องซึ้งสามช่องแล้วแต่แอดมินจะกำหนด แล้วก็ปุ่มสามารถลบได้แก้ไขได้แล้วก็ปุ่มออเดอร์แล้วก็แหกเมนูออเดอร์ออเดอร์คือหากมีลูกค้าเติมเกมให้มาอยู่ในนั้นออเดอร์แต่คนจะมาปรากฏในนั้นเป็นแต่ละเพจให้มีปุ่มกดดูรายละเอียดหากกดดูรายละเอียดให้มีชื่อผู้ใช้ราคาสินค้าที่ลูกค้าซื้อนะคะแพ็คเกจที่ลูกค้าเลือก แล้วก็มีปุ่มยืนยันปฏิเสธแล้วก็ปุ่มข้อความหักกดดูรายละเอียดลูกค้าคนนั้นหากกดหากแอดมินเติมเงินเสร็จหรือเติมเกมให้ลูกค้าเสร็จให้กดปุ่มยืนยันหน้าสถิติของลูกค้าก็จะขึ้นสำเร็จหากแอดมินยังไม่กดให้ขึ้นรอห้าเป็นภาษาลาวหรือรอสักครู่หากแอดมินกดยืนยัน อนุมัติในหน้าออเดอร์ลูกค้าจะได้รับเพชรลูกค้าจะได้รู้ หากปฏิเสธปุ่มสีแดงในหน้าหรือหน้าประทัดของลูกค้าให้ขึ้นไม่สำเร็จแล้วก็จำนวนเงินที่ลูกค้าซื้อนั้นหักกดปฏิเสธไปเงินจะเด้งกลับคืนกระเป๋าของลูกค้าแล้วก็ปุ่มข้อความคือสามารถกรอกข้อความส่งลูกค้าได้ค่ะหากมี หรือว่าแล้วก็เพิ่มระบบตั้งค่าสามารถมีตั้งค่าทั่วไปตั้งค่าสีแล้วก็กรอกข้อมูลติดต่อกรอกข้อมูลสถิติเดี๋ยวก็อย่าลืมเมนูสมัครสมาชิกเข้าสู่ระบบให้มีปุ่มสมัครสมาชิกใส่ชื่ออีเมลรหัสกรอกยืนยันรหัสอย่างน้อยแปดตัวมีปุ่มกดสมัครแล้วก็ปุ่มเข้าสู่ระบบให้ใส่ชื่อหรืออีเมล แล้วก็ปุ่มเข้าสู่ระบบหากแอดมินเอาอีเมลนี้ไปสมัครให้เป็นแอดมินคนแรกทันทีนี่คืออีเมลแอดมินหากเอาอีเมลนี้ไปสมัครจะได้รับสิทธิ์แอดมินทันทียังคนเดียวหนึ่งบัญชีหนึ่งอีเมลสามารถสมัครได้แค่หนึ่งบัญชีย้ำหนึ่งอีเมลสามารถสมัครได้แค่หนึ่งบัญชี
